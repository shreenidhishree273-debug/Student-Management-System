# Student Management System

## 1. Project Overview

The Student Management System is a simple web-based application developed using HTML, CSS, and JavaScript.

This project helps manage student records easily. Users can add, view, search, edit, and delete student details through a user-friendly interface.

## 2. Objectives

- To maintain student records digitally.
- To reduce manual record-keeping.
- To make searching student details easy.
- To provide a simple and user-friendly interface.
- To store student information in browser storage.

## 3. Technologies Used

- **HTML:** Creates the structure of the web application.
- **CSS:** Provides styling and layout.
- **JavaScript:** Handles student records and application functionality.
- **LocalStorage:** Stores student data in the browser.

## 4. Features

1. Add new student details.
2. View all student records.
3. Edit existing student information.
4. Delete student records.
5. Search students by name, roll number, email, or department.
6. Display total number of students.
7. Display department-wise count of departments.
8. Display male and female student counts.
9. Save student records using browser LocalStorage.
10. Responsive design for different screen sizes.

## 5. Student Details

The application stores the following information:

- Roll Number
- Student Name
- Email Address
- Phone Number
- Department
- Year of Study
- Gender

## 7. How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open the `student_management.html` file.
4. Run the file using a web browser such as Google Chrome or Microsoft Edge.
5. Enter student details in the form.
6. Click the Add Student button to save the record.
7. Use the Edit, Delete, and Search options to manage records.

No additional software installation or database setup is required.

## 8. Working of the Project

The application allows users to enter student information through an HTML form.

JavaScript validates the entered details and adds them to the student records table. Users can edit or delete records whenever required.

The search feature filters student records based on the entered keyword.

LocalStorage is used to save student data in the browser, allowing the records to remain available after refreshing the page.

## 9. Advantages

- Easy to use.
- Saves time in managing student records.
- Reduces manual work.
- Provides quick searching and editing.
- Does not require a separate database server.
- Suitable for learning basic web development.

## 10. Limitations

- Data is stored only in the browser's LocalStorage.
- Records are not shared between different devices.
- No user login or authentication system is included.
- It is not connected to a backend or MySQL database.

## 11. Future Enhancements

- Connect the application to a MySQL database.
- Add student login and administrator login.
- Add attendance management.
- Add marks and academic performance tracking.
- Generate student reports.
- Add data export functionality.

## 12. Conclusion

The Student Management System is a beginner-friendly web development project that demonstrates how HTML, CSS, and JavaScript can be used to create a functional student record management application.

It provides basic CRUD operations (Create, Read, Update, and Delete) and helps users manage student information efficiently.
